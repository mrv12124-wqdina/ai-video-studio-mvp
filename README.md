# 小说短片工作台

## 当前可用：基本制作流程（不需要模型）

在仓库目录运行 `npm install`、`npm run dev` 后打开 `http://localhost:3000`。当前首页提供：

- 小说粘贴、章节标题识别和按段落拆集；镜头按标点与字数拆分
- **不再自动猜人物**，角色需手工确认并填写外观设定
- 分集、镜头文本、镜头时长和视觉提示词可编辑
- 提示词根据所选镜头、手动角色设定和统一画风组成；需人工检查
- 浏览器本地保存草稿，支持 JSON 项目导入/导出备份
- 浏览器系统中文语音试听，以及文字分镜预览

本地保存仅限当前浏览器/电脑，不是服务器数据库。旁白是浏览器语音预览，不会进入导出视频。预览画面是文字故事板，不是 AI 生成画面。此阶段不伪造生成完成状态，也不使用占位视频。

## ComfyUI（模型下载完成后接入验证）

`http://localhost:3000/comfy` 是本机 ComfyUI 工作流接口页面。生成端点为 `http://127.0.0.1:8188`，需要 ComfyUI 与 Next.js 在同一台电脑运行。生成需要匹配的 API 工作流、模型及节点；模型下载前只能验证连接，不能完成真实画面生成。

## 开发

需要 Node.js 与 npm：

```bash
npm install
npm run dev
```
