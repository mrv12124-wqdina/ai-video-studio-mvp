# AI Video Studio

本仓库包含一个不需安装运行环境的浏览器自动剪辑工作台，以及 Next.js 开发版。

## 单文件自动剪辑工作台（Windows 最简单）

打开 [`ai-video-studio.html`](./ai-video-studio.html)，点击 **Download raw file** 下载，然后双击用最新版 Edge 或 Chrome 打开。无需 Git、Node.js、npm 或 API 密钥。

### 当前可实际使用的功能

- 导入本地视频和图片，自动排成分镜
- 将脚本按句拆分成可编辑字幕，烧录到导出画面
- 在没有素材时制作带动态字幕的文字分镜卡片
- 自定义人物称呼与头像标识
- 浏览器中文朗读试听
- 添加自己的配音与音乐音轨并混入视频
- 预览并导出 WebM 视频

所有素材在本机浏览器处理。为避免夸大：这不是文字直接生成影视画面的生成式模型，也不提供真正 AI 人物建模或自动生成自然配音；浏览器朗读仅用于试听，导出配音请上传音频。电影级文字转视频、角色一致性等需要接入付费云端服务/API，或配置本地大型模型和显卡。上传的音乐应确保有使用授权。

## 开发者版

```bash
npm install
npm run dev
```

然后访问 <http://localhost:3000>。开发版目前仍是早期演示，需要额外接入真实视频生成服务后才能由纯文字生成 AI 影像。
