# 小说短片工作台

面向小说改编视频发布的浏览器工作流：

- 粘贴完整小说，按章节、集数和镜头字数自动拆分
- 自动识别常见人名并生成人物档案
- 可编辑分集标题和人物卡片
- 自动生成分镜字幕画面与竖屏/横屏/方形画幅
- 使用浏览器配音朗读或上传项目配乐
- 导出当前分集的 WebM 视频及完整项目 JSON
- 无需 Git、Node.js、API 密钥或服务器

打开 [`novel-video-studio.html`](./novel-video-studio.html)，下载后双击即可在最新版 Edge 或 Chrome 使用。

## 使用流程

1. 粘贴拥有改编权的小说正文。
2. 设置作品名、每集字数、镜头字数和画幅。
3. 点击“自动拆章节与分镜”。
4. 编辑分集标题和人物档案。
5. 撆放旁白预览、上传配乐并导出分集。

## 当前边界与后续接入

本工具现在是本地自动剪辑与剧本分解工具，不会凭空生成电影级画面、真实人物建模或克隆配音，也不提供自动网素材抓取或平台发布。生成真实 AI 影像、人物一致性、自然配音和素材搜索需要在服务端接入视频、TTS、角色参考图及素材库 API，并配置密钥、存储、队列和版权审查。

不要导出和传播不拥有改编权、配音权或素材授权的作品。发布前还应遵守抖音、YouTube 等平台对 AI 生成内容标识、音乐使用和商业权益的要求。
